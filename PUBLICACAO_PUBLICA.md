# Preparação para repositório público

Esta pasta é uma cópia de publicação do projeto **Laboratório de Hardware**, preparada a partir do repositório privado em 16/10/2026.

## Medidas aplicadas

- histórico Git privado não foi copiado;
- documentos mantidos são as versões anonimizadas já presentes no projeto;
- arquivos de backup/transitórios foram excluídos da cópia pública;
- o arquivo legado `lab_system.rar` foi excluído por ser um pacote binário redundante e inadequado para auditoria pública;
- `tmp_probe.txt` foi excluído;
- `.env.example` foi mantido apenas com valores de exemplo, sem credenciais reais;
- esta cópia deve iniciar um histórico Git novo e independente.

## Regra de privacidade

Não adicionar nomes, e-mails pessoais, matrículas, credenciais, tokens ou outros identificadores desnecessários de estudantes. Para documentação acadêmica, prefira identificadores de grupo, papéis ou exemplos fictícios.
