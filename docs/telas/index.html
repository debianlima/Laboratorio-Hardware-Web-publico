Módulo de Agendamentos

Não implementado. Schema do banco de dados pronto (laboratorios, agendamentos em docker/mysql/init.sql).

Fluxo de QR Code

  1. Administrador cadastra item em itens/cadastrar.php
  2. Sistema gera QR Code via itens/qrcode.php apontando para itens/ver.php?id=X
  3. Etiqueta com QR Code é impressa e fixada no componente físico
  4. Usuário escaneia QR Code com celular → abre itens/ver.php?id=X no navegador
  5. Visualização de detalhes do item sem necessidade de login

Características de Interface

  • Navegação: menu superior com links para Itens, Empréstimos, saudação ao usuário e logout
  • Responsividade: Bootstrap 5.3 com layout adaptável para mobile
  • Segurança: CSRF tokens em formulários, prepared statements, rate limiting no login
  • QR Code: biblioteca qrcodejs via CDN, geração e impressão de etiquetas
  • Acessibilidade: labels semânticos, contraste adequado, navegação por teclado
