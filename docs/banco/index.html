Notas

Duas tabelas de inventário: O sistema possui itens (com código de patrimônio, usado pelo módulo Itens) e equipamentos (simplificada, usada pelo módulo Empréstimos). São estruturas paralelas que podem ser unificadas em versão futura.
Migration: role → tipo (2026-05-21): A coluna role na tabela usuarios foi renomeada para tipo via migration migrations/2024-05-21-rename_role_to_tipo.sql. O código PHP correspondente foi atualizado (verificarPermissao(['administrador'])). Este é o formato canônico do sistema.
login_attempts: Tabela auxiliar criada automaticamente pelo rate limiter (LIM-274). Permite rastrear tentativas de login por IP com bloqueio de 5 tentativas a cada 15 minutos. Gerenciada em src/config/rate_limit.php e auditável via src/admin/login_log.php.
