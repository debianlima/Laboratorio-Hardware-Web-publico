Seções Alteradas — Antes da Correção

O artigo docs/artigo.html (versão 2.1) continha as seguintes divergências identificadas nas revisões LIM-266 e LIM-249:

RN-02 — Controle de acesso por papel (linha 523)

RN-02 | Controle de acesso por papel | Apenas usuários com papel "admin" ou "librarian" (coluna role) podem gerenciar usuários e acessar relatórios. O campo tipo (administrador/padrao) é utilizado na sessão de login. | Autenticação

Problema: Coluna role não existe no schema oficial (docker/mysql/init.sql). A coluna real é tipo ENUM('administrador','padrao').

Dicionário de Dados — usuarios (linha 1095)

<tr><td>role</td><td>VARCHAR(20)</td><td>YES</td><td>NULL</td><td>Papel de autorização (admin/librarian) — usado em <code>auth.php</code></td></tr>

Problema: Linha descreve coluna role que não existe no schema real. O código auth.php consulta esta coluna, mas ela nunca foi criada no banco.

Seção 17 — Nota de Documento Legado (linhas 1522-1528)

<div class="contingency-box">
  <strong>⚠ Documento Legado — Cópia em src/doc/artigo.html:</strong>
  O arquivo <code>src/doc/artigo.html</code> é uma cópia legada do artigo...
  está congelado como <strong>versão 2.0</strong> e não reflete o estado atual do sistema.
</div>

Problema 1: Afirma que src/doc/artigo.html está congelado como v2.0, mas o arquivo real exibe "VERSÃO OFICIAL" e "Versão 2.1".

Problema 2: src/doc/artigo1.html (também presente no repositório) não é mencionado como cópia legada.
