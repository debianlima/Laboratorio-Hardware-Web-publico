Estado das seções 5 e 9.1 antes das correções

Achado 1 — Seção 5 (Regras de Negócio) antes da correção

A tabela de regras de negócio não possuía coluna de status de implementação. A RN-10 (Log de auditoria) era listada como regra vigente, sem indicar que sua implementação está pendente (vinculada a BL-11 no backlog).

Tabela 5.1 — REGRAS DE NEGÓCIO (ORIGINAL)
┌───────┬──────────────────────────┬──────────────────────────────────────────────┬────────────────┐
│ ID    │ Regra                    │ Descrição                                    │ Módulo         │
├───────┼──────────────────────────┼──────────────────────────────────────────────┼────────────────┤
│ RN-01 │ Autenticação obrigatória │ Todas as páginas, exceto login...             │ Autenticação   │
│ RN-02 │ Controle de acesso...    │ Apenas usuários com perfil "administrador"... │ Autenticação   │
│ ...   │ ...                      │ ...                                          │ ...            │
│ RN-10 │ Log de auditoria         │ Toda operação de criação, edição...           │ Auditoria      │
│ ...   │ ...                      │ ...                                          │ ...            │
└───────┴──────────────────────────┴──────────────────────────────────────────────┴────────────────┘
→ Sem coluna de status. RN-10 não indica que implementação é pendente.

Achado 2 — Seção 9.1 (Mapa de Navegação) antes da correção

A tabela de telas não possuía coluna "Tipo" para diferenciar arquivos de produção de protótipos. Telas como T-06, T-07, T-08, T-09 e T-10 (em fontes_recebidas/prototipos/) eram listadas ao lado de telas de produção (src/*) sem distinção de ambiente.
