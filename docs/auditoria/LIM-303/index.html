LIM-303 — Corrigir divergência documental em src/doc/artigo.html (role x tipo)

Correção de nomenclatura obsoleta: papel/role → perfil/tipo no artigo legado

Resumo

Correção de divergência documental no arquivo src/doc/artigo.html (cópia legada, versão 2.0), que ainda utilizava a nomenclatura antiga da coluna role com valores "admin" ou "librarian" para descrever o controle de acesso do sistema. O banco de dados foi migrado para utilizar exclusivamente a coluna tipo com valores ENUM('administrador', 'padrao').

Dois pontos foram corrigidos:

  • RN-02 (Tabela 5.1): "papel" → "perfil", coluna role → tipo, valores "admin/librarian" → "administrador"
  • Dicionário de dados (usuarios): Remoção da coluna role VARCHAR(20) que não existe mais no schema — foi renomeada para tipo
