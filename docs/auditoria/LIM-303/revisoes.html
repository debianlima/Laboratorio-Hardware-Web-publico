Início Artigo Auditoria LIM-303

Revisão 1 — RN-02: Nomenclatura de controle de acesso

ItemOriginalCorrigidoMotivo
Título da regra "Controle de acesso por papel" "Controle de acesso por perfil" O termo "papel" era tradução literal de "role" (nomenclatura anterior). O sistema atual utiliza "perfil" como conceito de negócio.
Valores de perfil "admin" ou "librarian" "administrador" Os valores "admin" e "librarian" eram da coluna role antiga. O sistema atual usa ENUM('administrador', 'padrao').
Coluna referenciada role tipo A migration 2024-05-21-rename_role_to_tipo.sql renomeou a coluna. O schema atual não contém role.
Descrição adicional "O campo tipo (administrador/padrao) é utilizado na sessão de login." "O campo tipo é armazenado na sessão durante o login e utilizado para controle de acesso." Harmonização com a redação da versão oficial (docs/artigo.html), evitando duplicidade de informação sobre valores.

Impacto: Elimina informação desatualizada que poderia confundir leitores sobre o mecanismo real de controle de acesso.

Revisão 2 — Dicionário de Dados: remoção de coluna inexistente

ItemOriginalCorrigidoMotivo
Coluna role Presente na tabela usuarios como VARCHAR(20), nullable, descrito como "Papel de autorização (admin/librarian)" Removida A coluna role não existe no schema atual. Foi renomeada para tipo na migration de 2024. Sua presença no dicionário de dados documentava um schema que não corresponde à realidade.

Impacto: O dicionário de dados agora reflete com precisão o schema real do banco de dados, essencial para consistência documental e auditoria técnica.

Resumo de Impacto no Projeto

As correções são de gravidade ALTA por afetarem a precisão técnica da documentação acadêmica, mas de baixo esforço por se limitarem a ajustes pontuais de texto. Não há alteração de código, banco de dados ou comportamento do sistema.
