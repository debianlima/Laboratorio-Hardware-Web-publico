Diagnóstico da Divergência

Problema Identificado

O arquivo src/doc/artigo.html (versão 2.0) descreve o controle de acesso do sistema utilizando a nomenclatura antiga baseada na coluna role com valores "admin" ou "librarian". No entanto, o banco de dados foi migrado (migration 2024-05-21-rename_role_to_tipo.sql) para utilizar a coluna tipo com valores ENUM('administrador', 'padrao').

Locais da Divergência

#SeçãoLocal (src/doc/artigo.html)Texto IncorretoTexto CorretoGravidade
1 RN-02 (Tabela 5.1) Linha 523 "papel", coluna role, valores "admin" ou "librarian" "perfil", coluna tipo, valor "administrador" ALTA
2 Dicionário de Dados — usuarios Linha 1095 Coluna role VARCHAR(20) listada como campo existente Coluna role não existe mais — foi renomeada para tipo ALTA

Evidências do Código Fonte

  • Migration: migrations/2024-05-21-rename_role_to_tipo.sql — renomeia a coluna role para tipo (CHANGE COLUMN role tipo VARCHAR(20) NOT NULL)
  • Schema atual: docker/mysql/init.sql linha 13 — tipo ENUM('administrador', 'padrao') NOT NULL DEFAULT 'padrao'
  • Auth: src/config/auth.php linha 12 — function verificarPermissao($tipos = ['administrador'])
  • Login: src/login.php linha 49 — $_SESSION['tipo'] = $user['tipo'];

Análise de Impacto

As divergências encontradas afetam a precisão técnica do artigo acadêmico. A descrição incorreta do mecanismo de controle de acesso (mencionando role e valores que não existem no sistema) compromete a confiabilidade da documentação e pode induzir a erros de interpretação por leitores técnicos.
