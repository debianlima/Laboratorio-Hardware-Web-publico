Identificação

Issue: LIM-79 Data: 2026-05-19 Agente: CEO Técnico Local Status: Implementado

Visão Geral

O sistema de QR Code permite identificar fisicamente cada componente do laboratório através de etiquetas com código QR. Ao escanear a etiqueta com a câmera do celular, o usuário é direcionado para a página de detalhes do item.

Tecnologia

  • Biblioteca: qrcodejs via CDN (sem dependência Composer)
  • URL do QR: http://{$_SERVER['HTTP_HOST']}/itens/ver.php?id={item_id}
  • Impressão: CSS @media print otimizado para etiquetas
  • Compatibilidade: Qualquer smartphone com câmera e navegador

Regras de Negócio

  1. Cada item possui um QR Code único baseado no seu ID
  2. O QR Code aponta para URL absoluta do servidor (funciona em rede local)
  3. A página ver.php não requer autenticação para leitura rápida
  4. A etiqueta contém: nome do item, código de patrimônio e tipo
  5. A impressão é otimizada para tamanho de etiqueta física
