# Inventário de Materiais Recebidos

## Estrutura Consolidada

### `fontes_recebidas/` — Centralização dos materiais estudantis

| Subpasta | Conteúdo | Origem |
|----------|----------|--------|
| `prototipos/lab_system/` | Protótipo PHP completo (CRUD usuários/labs/itens) | `Documentos/grupo 5 e 1/lab_system/` |
| `prototipos/*.php` | Relatórios do Módulo 4 | `Modulo_4_relatorios/code/` |
| `documentacao/` | Referências para PDFs, DOCXs, assets | Raiz, `Documentos/`, `assets/` |
| `forum/` | Referência para instalação Flarum | `Modulo_5_forum/codigos/flarum/` |

### Arquivos na raiz (não movidos)

| Arquivo | Tipo | Tamanho | Observação |
|---------|------|---------|------------|
| `lab_system.rar` | RAR compactado | ~21MB | Protótipo original dos alunos |
| `documentacao-do-projeto.pdf` | Documento | ~20MB | PDF do projeto |
| `LAB HAD.docx` | Documento | ~2MB | Documento do laboratório |
| `Relatório lab system.pdf` | Documento | ~19MB | Relatório do sistema |
| `Requisitos .docx` | Documento | ~312KB | Requisitos do sistema |

### Diretórios originais preservados

| Diretório | Conteúdo |
|-----------|----------|
| `Documentos/` | Documentação + protótipo PHP completo |
| `Modulo_4_relatorios/` | Código de relatórios + imagens |
| `Modulo_5_forum/` | Instalação Flarum (forum) |
| `assets/` | CSS + imagens do sistema |
| `login/` | Página de login estática (protótipo) |

## Rastreabilidade

- **Nenhum arquivo original foi deletado ou sobrescrito.**
- Arquivos grandes (RAR, PDF, DOCX) foram apenas referenciados, não copiados.
- Cópias menores (PHP) foram feitas para `fontes_recebidas/prototipos/`.
