# Paperclip — pacote Markdown de agentes, governança e resultados

**Projeto:** Laboratório de Hardware 2025  
**Data de consolidação:** outubro de 2026  
**Finalidade:** disponibilizar arquivos Markdown de referência para os agentes e para o gerenciamento do projeto.

## Importante: origem e fidelidade

Este pacote foi **reconstruído a partir dos registros históricos e da apresentação consolidada**. Não é uma exportação byte a byte do workspace nem substitui os arquivos originais do repositório. Onde o conteúdo original não estava disponível, os documentos registram explicitamente a lacuna, em vez de inventar resultados.

Antes de instalar este pacote no workspace:
1. Faça backup dos arquivos existentes.
2. Compare cada documento com a versão canônica no repositório.
3. Preserve histórico e alterações locais.
4. Atualize os campos marcados como `A CONFIRMAR` com evidência real.
5. Não use os arquivos reconstruídos para afirmar que uma issue está atualmente concluída sem consultar o board, os runs, o Git e os testes.

## Estrutura

- `AGENTS.md`: governança comum.
- `agents/`: contratos operacionais reconstruídos para os nove papéis identificados no recorte.
- Arquivos Markdown na raiz: auditoria, backlog, checklist, histórico, pendências, riscos e requisitos.
- `docs/agentes/`: rotina de heartbeat.
- `docs/estudos/`: estudos e testes referenciados nos registros.
- `docs/`: handoffs, revisões e artefatos de issues.
- `docs/auditoria/`: mapa de rastreabilidade de evidências.
