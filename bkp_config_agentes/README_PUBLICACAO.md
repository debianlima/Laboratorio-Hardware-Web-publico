# Nota de publicação — backup parcial dos agentes

Esta pasta foi incorporada à cópia pública com o nome `bkp_config_agentes/` para preservar a documentação de configuração e governança dos agentes usada no experimento.

## O que este backup preserva

O conjunto reúne arquivos Markdown e manifestos que descrevem papéis dos agentes, regras de governança, backlog, requisitos, auditorias, histórico de desenvolvimento, riscos e documentação de apoio. Ele é útil para estudar a organização do experimento e auxiliar uma reconstrução futura.

## O que este backup não preserva

Este material **não é um dump completo do Paperclip**. Ele não garante a presença de toda a base operacional, estados de execução, sessões, filas, históricos externos, cache, credenciais ou outros dados transitórios do ambiente original.

O conteúdo deve, portanto, ser tratado como **backup parcial e reconstruído**. Uma restauração futura precisa validar dependências, versões, caminhos e configurações antes de executar qualquer experimento.

## Privacidade

Na cópia destinada à publicação, referências de infraestrutura interna foram substituídas por valores anônimos ou reservados para documentação. Credenciais reais não devem ser adicionadas a esta pasta.
